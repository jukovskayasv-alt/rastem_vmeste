# Проверка пилота 0.2

Дата: 17.09.2026.

## Автоматические проверки

- Полный набор `python3 -m unittest discover -s tests -v`: 83 теста, все пройдены (5,264 с; код `0fdc6ee`).
- После смены цели выполнен узкий набор `python3 -m unittest tests.test_bootstrap -v`: 9 тестов пройдены, включая точный allowlist `jukovskayasv-alt/rastem_vmeste`, push-фильтр `skif` и сохранённую проверку `private == true`. Полный набор повторно не запускался, поскольку прикладной код не менялся.
- Компиляция Python-модулей и проверка структуры GitHub Actions пройдены.
- Проверены доступ по числовому ID в личном чате, принадлежность задач владельцу, повторная доставка сообщений и подтверждение точного текста публикации.
- Проверены расчёты в копейках, даты конца месяца и високосного года, CSV/ICS, обязательные поля и режим демонстрационных договоров.
- Проверены ограничение циклов исправления PDF, отказ при непрошедшей проверке и обработка ошибок ответов модели.
- Проверены идентичность четырёх ботов и отсутствие webhook, свежесть сигнала работы конкретного выпуска и ненулевой код при неполной конфигурации.
- Проверены обновление, отказ до остановки рабочей версии, неготовая новая версия, возврат прежнего образа, ошибка первой установки, взаимное исключение запусков и восстановление журнала при ошибке записи. В этих тестах внешние вызовы Docker заменены контролируемыми ответами; сам алгоритм обновления выполняется.
- Проверены точный разрешённый репозиторий, официальный архив исполнителя GitHub и SHA-256, безопасная распаковка, отказ от замены существующей регистрации, скрытый ввод ключа, отсутствие ключа в аргументах процесса порядок подготовки служб и безопасная обработка превышения времени системных команд. Системные команды в тестах подменены.

## Проверенные ранее демонстрационные материалы

В версии 0.1 проверены два последовательных запуска `demo` без перезаписи. Обе формы DOCX визуально проверены после рендеринга: по три страницы. PDF-пример из шести страниц также визуально проверен. Эти генераторы в версии 0.2 не менялись; их тесты входят в общий набор.

## Границы проверки и подключения

Действующие аккаунты Telegram и ИИ, публикация в канал, настоящая Docker-сборка, установка на ВМ и длительная работа не проверены. В рабочей среде проверки Docker недоступен; тесты его вызовов не доказывают успешный запуск контейнера на сервере. Установщик не запускался: пакеты, пользователи и службы сервера не изменялись.

Репозиторий `jukovskayasv-alt/rastem_vmeste` существует и подключение имеет право загрузки, но на момент подготовки он публичный. Для СКИФ предназначена отдельная ветка `skif` с приложением в корне; её загрузка и запуск GitHub Actions ещё не подтверждены. Владелец должна сначала сделать репозиторий Private и только затем устанавливать self-hosted runner. Работающий runner и реальный deploy на ВМ не проверены. Для запуска также нужны однократная установка владельцем на существующей ВМ, четыре действующих токена ботов, числовой ID владельца и доступный API-аккаунт. Секреты не входят в пакет.

Сигнал `health` подтверждает свежесть служебного состояния версии, а не правильность ответов ИИ и не выполнение сделки. Откат восстанавливает код; рабочая база сохраняется и автоматически назад не переводится.

Офлайн-PDF имеет статус `demo_structural_only`: визуальная проверка моделью в демонстрации не запускалась. Договоры — неподписанные демонстрационные черновики. Лица и идентификатор `DEMO-ONLY` в них вымышлены.
