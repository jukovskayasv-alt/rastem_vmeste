СЛЕДУЮЩИЙ ШАГ
В существующем репозитории jukovskayasv-alt/rastem_vmeste сначала
смените видимость на Private. Не устанавливайте self-hosted runner,
пока репозиторий публичный. Код СКИФ загружается в отдельную ветку skif,
в корень ветки; main и существующий сайт остаются без изменений.
Когда репозиторий уже Private, runner показывает Online и /opt/skif/.env
заполнен, отправьте новый commit в ветку skif: например, добавьте через
GitHub безвредное уточнение в README.md и выберите Commit changes в skif.
Именно новый push запускает первый deploy; смена видимости и установка
runner сами его не запускают.

ПЕРВОНАЧАЛЬНОЕ ПОДКЛЮЧЕНИЕ СЕРВЕРА
Инструкция для владельца или специалиста: ops/README_RU.md.
Установщик: ops/bootstrap_host.py. Запускать на существующей Ubuntu ВМ.
Нужно настроить ещё три бота, четыре действующих токена, числовой
Telegram ID владельца и доступный API-аккаунт с подходящей моделью.
Все секреты вводятся только на сервере в /opt/skif/.env, не в чат
и не в GitHub. Включать два экземпляра с одинаковыми токенами нельзя.

КАК БУДЕТ ПРОХОДИТЬ ДАЛЬНЕЙШАЯ РАБОТА
Ты описываешь изменения в нашем чате → код обновляется на GitHub →
проходят тесты → подключённый сервер устанавливает новую версию.
При ошибке запуска он пытается вернуть прежний образ. Рабочая база
сохраняется, автоматический откат базы данных не выполняется.
Проверка запуска не заменяет проверку качества ответов на реальных задачах.

ДЛЯ ЭКОНОМИИ
Математика, календарь и договорные шаблоны выполняются без ИИ.
На исправление PDF отводится максимум три попытки.
Лимит 40 вызовов ИИ в сутки — ограничение количества, не денежный бюджет.
API и существующий сервер оплачиваются отдельно от подписки ChatGPT.
Canva для этой системы не нужна.

ПРИОРИТЕТЫ СКИФ
1. Пилотная версия проекта: состав, бюджет, этапы.
2. Уточнение ПЗЗ и возможности получения ГПЗУ по конкретным участкам.
3. Подтверждённые карточки участков и согласованные материалы продаж.

Блог публикуется только после подтверждения точного текста.
Подписание, расчёты и регистрация сделки остаются за участниками
сделки и уполномоченными организациями.
