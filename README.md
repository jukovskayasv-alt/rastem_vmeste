# Элир — AI Family & Work Chat

Мобильный чат-интерфейс с главным помощником Элиром и командой специалистов на OpenAI.

## Уже есть
- режимы Личное / Семья / Работа;
- Элир + Стратег + Продажник + Финансист + Юрист + Контент + Технарь;
- ручной выбор специалиста;
- кнопка «Созвать совет» — несколько агентов параллельно дают внутренние записки, Элир собирает итог;
- серверный OpenAI API: ключ не попадает в клиент;
- адаптивный mobile-first интерфейс.

## Запуск
1. npm install
2. добавить OPENAI_API_KEY=... в .env.local
3. npm run dev
