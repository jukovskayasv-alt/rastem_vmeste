# Проверка PDF-презентаций СКИФ

Вход: `generate_deck(brief, project, assets_dir, out_dir, model=None, max_attempts=3)`.
Выход: словарь с `pdf`, `report`, `previews`, `status`, `attempts`. Все пути абсолютные.
Отдельный уникальный префикс каждого запуска исключает перезапись соседней задачи.

## Что делает генератор

1. Проверяет карточку предложения: `offer.price_rub=600000`, `offer.area_m2=600`, `offer.plot_id=null`. Отсутствующая, неполная или конфликтующая карточка блокирует выпуск. Изменение цены требует одновременно пересмотреть утверждённые формулировки.
2. При подключённой модели получает JSON на 5–8 слайдов. Модель выбирает точные заголовки и абзацы из утверждённого каталога, порядок и 1–2 фотографии. Новые факты, обещания, картинки по URL и произвольные пути не принимаются. Пожелания из брифа не отменяют эти ограничения.
3. Проверяет формат 960 × 540 pt, длину текста, `dataPrice`, существование и качество файлов, обязательные оговорки. Цена и предупреждение об отсутствии кадастровой привязки находятся на одном слайде. Участок-ориентир :2371 площадью 604 м² не получает цену автоматически.
4. Создаёт PDF с настоящим текстом и встроенными кириллическими шрифтами. Карты и фото вписываются без растяжения и без обрезки границ; источники указаны под изображениями. Карты сопровождает атрибуция OpenStreetMap.
5. Открывает PDF через PyMuPDF, проверяет размер и число страниц, извлекаемый текст. Рендерит **каждую** страницу в PNG 1440 × 810.
6. При подключённой модели делает отдельный вызов визуального критика со всеми PNG. Критик проверяет читаемость, пересечения, изображения, смысловые оговорки и подписи. Его положительный ответ с непустым списком дефектов или ответ неверного формата считаются отказом.
7. Возвращает выявленные ошибки в следующий запрос генерации. Попыток не больше трёх даже при большем значении параметра. Ошибка не вызывает бесконечных исправлений.

## Статусы

| Статус | Значение |
| --- | --- |
| `demo_structural_only` | Без внешнего ИИ: образец прошёл программные проверки и рендеринг. Это не визуальная ИИ-проверка. |
| `needs_owner_review` | Программные проверки и отдельный визуальный критик приняли результат. Владелец должен просмотреть PDF перед отправкой. |
| `qa_failed` | Карточка противоречит утверждённым данным или исчерпан лимит исправлений. `pdf` пустой, `previews=[]`; доступен JSON-отчёт. |

Отклонённые промежуточные файлы могут сохраняться рядом с отчётом для диагностики. Отправляющий бот должен использовать только пути из верхнего уровня результата и учитывать статус. Наличие PDF в каталоге не означает, что его можно отправлять.

ИИ-проверка не доказывает безупречность и не заменяет проверку владельца или документов участка. Без внешних учётных данных тесты подтверждают локальную генерацию, ограничение попыток и обработку запрограммированных ответов, а не качество реальной модели.

## Контракт модели

Объект имеет метод `json(system, prompt, schema, images=None, web=False) -> dict`.
Для генерации `images=None`; для критика передаются пути всех PNG. Критик возвращает `{"pass": true/false, "issues": ["описание дефекта"]}`. Здесь нет веб-поиска или внешней публикации. Ошибки API записываются по имени класса, без тела запроса и возможных ключей доступа.

## Исходные материалы

- `beach.jpeg` ← `image3.jpeg`, побережье из материалов проекта.
- `field.jpeg` ← `image4.jpeg`, фактический вид территории.
- `regional_map.jpeg` ← `image5.jpeg`, региональная схема на данных OpenStreetMap.
- `local_map.jpeg` ← `image7.jpeg`, местная схема на данных OpenStreetMap.
- `objects.jpeg` ← `image9.jpeg`, существующие объекты; принадлежность конкретному участку не подтверждается фотографией.
- `electricity.jpeg` ← `image13.jpeg`, дорога и линия электроснабжения.
- `fonts/` — DejaVu Sans, Sans Bold и Serif с файлом лицензии.

Генеративные изображения будущей застройки не используются. Полноценное редактирование произвольного текста и автоматический выбор новых фотографий не входят в первую версию.

## Локальная проверка

Из корня проекта: `python -m unittest discover -s tests -p test_presentations.py -v`.
Тесты открывают реальные PDF и PNG; внешний модельный API заменяет небольшой сценарный адаптер. Проверяются ремонт фактического и визуального дефекта, жёсткий предел попыток, неправильный ответ критика, отсутствие фото и конфликт цены.
